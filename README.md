# Master Thesis – Multi-Agent RAG System

This repository contains the code and experiments for my Master's thesis in Data Science at the University of Stavanger.

## Project Description
The thesis investigates how a **multi-agent architecture** can be used in a
**Retrieval-Augmented Generation (RAG)** system to manage and prioritize
information from multiple and evolving knowledge sources.


## Setup
```bash
conda create -n myenv python=3.11
conda activate myenv
pip install -r requirements.txt
```
